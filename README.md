# Moved to arctop/homebrew-tap

The Seamless Homebrew tap now lives at
[arctop/homebrew-tap](https://github.com/arctop/homebrew-tap).
New releases are published there only.

New installs:

```sh
brew install arctop/tap/seamless
```

If you installed from this tap, switch with:

```sh
brew uninstall --cask seamless
brew untap 0spoon/tap
brew install --cask arctop/tap/seamless
```

Seamless: https://thereisnospoon.org
